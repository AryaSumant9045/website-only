Where your keys live privacy

Keys are stored in this browser's localStorage and sent with each run to your own local server, which holds them in memory for that request only. Nothing is written to disk, nothing goes to a third party except the provider you chose.

Sharing this Mac? Hit Clear keys below. Restrict the Google key to Places API (New) and set a daily quota so a lost key cannot run up a bill.

Models & API OpenAI-compatible

Koi bhi OpenAI-compatible endpoint — OpenAI, OpenRouter, Groq, DeepSeek, Together, local Ollama, ya apna custom gateway. Ye pitch aur outreach likhne ke liye use hota hai.
